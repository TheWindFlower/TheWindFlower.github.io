# Portfolio (Neovim style)
1. Copy your existing `public/` folder (img, docs) into this project — paths are unchanged (`/public/assets/...`).
2. `npm install` then `npm run build` → static `dist/` (HTML/CSS/JS only). `npm run dev` to preview.
Keys: `:` command line, `:e projects`, `:lang fr`, `L` toggle language, `1-5` / `gt` `gT` switch tabs, `j k gg G` scroll.
